Geometrische Probleme

Was macht ein Problem geometrisch?

Ein typischer Fehler aus der Praxis: Eine Leitung wirkt im Modell kollisionsfrei oder ein Gebäude scheint “nah genug”, obwohl Distanz oder Lage im falschen Koordinatensystem berechnet wurden.

Geometrische Probleme drehen sich um:

  • Räumliche Objekte: Punkte, Linien, Flächen
  • Räumliche Beziehungen: enthält, schneidet, nächster
  • Koordinaten, Maße, Orientierungen

Problemklassen-Signatur:

  • Eingabe: Koordinaten, Formen, Abstände
  • Frage: Liegt A in B? Wie weit? Überlappen sie?
  • Ausgabe: Bool, Zahl oder neue Geometrie

Vektoralgebra

Geometrische Grundobjekte

Datenstrukturen

Punkt: (x, y) oder (x, y, z)

Liniensegment: Liste von 2+ Punkten

Polygon: Geordnete Punktliste, konzeptuell geschlossen

In vielen Datenformaten wird der erste Punkt am Ende wiederholt. In shapely darf die Schlusskante meist weggelassen werden, weil Polygon(...) sie automatisch ergänzt.

# Punkt
p = (3.0, 2.5)

# Liniensegment
linie = [(0, 0), (10, 5)]

# Polygon (Rechteck)
polygon = [
    (0, 0),
    (10, 0),
    (10, 5),
    (0, 5)
]

# shapely schließt das Polygon automatisch

Vektor-Operationen

Algorithmen

Abstand zwischen zwei Punkten:

\[d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}\]

Kreuzprodukt (Orientierung):

\[\vec{u} \times \vec{v} = u_x v_y - u_y v_x\]

  • Positiv → Punkt liegt links der Linie
  • Negativ → Punkt liegt rechts der Linie
  • Null → Punkt liegt auf der Linie

Anwendung des Kreuzprodukts:

  • Grundlage für Point-in-Polygon
  • Orientierung von Polygonecken
  • Kollisionserkennung
def kreuzprodukt_2d(u, v):
    return u[0]*v[1] - u[1]*v[0]

# Liegt (3,2) links von (0,0)→(5,5)?
u = (5-0, 5-0)  # Richtung
v = (3-0, 2-0)  # zum Punkt
k = kreuzprodukt_2d(u, v)
# k > 0 → links

Grundoperationen

Point-in-Polygon: Liegt ein Punkt in einer Zone?

Problem: Liegt Sensor in Gebäude? Liegt Adresse in Überschwemmungszone?

Ray-Casting-Algorithmus:

  1. Strahl vom Punkt nach rechts
  2. Zähle Schnitte mit Polygon-Kanten
  3. Ungerade Anzahl → Punkt liegt innen

Merksatz

Ungerade = drinnen. Gerade = draußen.

from shapely.geometry import Point, Polygon

zone = Polygon([
    (0,0),(10,0),(10,5),(0,5)
])
sensor = Point(3, 2)

# contains: Punkt vollständig innen?
print(zone.contains(sensor))   # True
print(zone.contains(Point(15, 2)))  # False

# within ist die Umkehrung
print(sensor.within(zone))     # True

Distanz und Schnitt

Distanz — kürzester Abstand zweier Geometrien:

from shapely.geometry import Point

krankenhaus = Point(5, 5)
unfallort   = Point(12, 8)

dist = krankenhaus.distance(unfallort)
print(f"{dist:.2f}")  # 7.62

Anwendung: Nächste Haltestelle, nächstes Krankenhaus, nächste Feuerwehr

Schnitt — überlappen sich zwei Geometrien?

from shapely.geometry import LineString

rohr1 = LineString([(0,0),(10,10)])
rohr2 = LineString([(0,10),(10,0)])

# Kreuzen sie sich?
print(rohr1.intersects(rohr2))  # True

# Wo genau?
punkt = rohr1.intersection(rohr2)
print(punkt)  # POINT (5 5)

Bibliothek

Kerntypen:

  • Point — Koordinate

  • MultiPolygon — z.B. Parzellengruppe

Kernoperationen:

from shapely.geometry import Point, Polygon

gebaeude = Polygon([
    (0, 0), (20, 0),
    (20, 15), (0, 15)
])

print(f"Fläche: {gebaeude.area} m²")
# Fläche: 300 m²

# 5m Pufferzone
puffer = gebaeude.buffer(5)
print(f"Mit Puffer: {puffer.area:.0f} m²")
# Mit Puffer: 729 m²

# Enthält ein Punkt die Zone?
sensor = Point(10, 7)
print(gebaeude.contains(sensor))  # True

Koordinatensysteme

Warum Projektionen wichtig sind

Problem: Die Erde ist eine Kugel — Karten sind flach.

WGS84 (EPSG:4326):

  • Koordinaten in Grad (Länge/Breite)
  • Standard für GPS, Google Maps, GeoJSON
  • 1 Grad ≠ 1 Meter!

Lokale Systeme (z.B. UTM, EPSG:25833):

  • Koordinaten in Metern
  • Geeignet für lokale Distanzberechnungen
  • Verzerrt über große Gebiete

Häufiger KI-Fehler

KI-generierter Code berechnet Abstände direkt aus WGS84-Koordinaten. shapely kennt kein KBS — distance() liefert Werte in den Einheiten der Koordinaten, also hier in Grad und nicht automatisch in Metern.

Projektionen im Code

Falsch — typischer KI-Output:

from shapely.geometry import Point

# Koordinaten in WGS84 (Grad)
berlin  = Point(13.405, 52.520)
potsdam = Point(13.064, 52.400)

dist = berlin.distance(potsdam)
# ≠ Meter! Einheit: Grad
print(dist)  # 0.35 — bedeutungslos

Problem: 0.35 Grad ≈ 35 km, aber shapely weiß das nicht.

Richtig — mit Projektion:

from pyproj import Transformer
from shapely.ops import transform

# WGS84 → UTM Zone 33N
t = Transformer.from_crs(4326, 25833,
                          always_xy=True)

berlin_utm  = transform(t.transform, berlin)
potsdam_utm = transform(t.transform, potsdam)

dist_m = berlin_utm.distance(potsdam_utm)
print(f"{dist_m:.0f} m")  # 28 422 m ✓

KI-Code mit shapely lesen — Aufgabe

KI-Code lesen

# KI-generiert: Gebäude im Radius finden
from shapely.geometry import Point, Polygon

def gebaeude_in_radius(gebaeude_liste, mittelpunkt_coords, radius_m):
    mittelpunkt = Point(mittelpunkt_coords)
    suchzone = mittelpunkt.buffer(radius_m)
    treffer = []
    for geb in gebaeude_liste:
        polygon = Polygon(geb['koordinaten'])
        if suchzone.intersects(polygon):
            treffer.append(geb)
    return treffer

Versteht den Code — nach dem CRS-Block

  1. buffer(radius_m) erzeugt eine Suchzone in den Einheiten der Eingabekoordinaten.
  2. intersects() genügt hier, weil auch teilweise überdeckte Gebäude gezählt werden sollen.
  3. Bei WGS84 in Grad fehlt vor dem buffer() eine Projektion in ein metrisches KBS.

KI-Fehler bei Geometrie erkennen

Häufige KI-Fehler:

  • Kein KBS angegeben oder verwendet
  • distance() auf WGS84-Koordinaten (Grad)
  • Bibliotheksverhalten zu Polygonringen falsch angenommen
  • Koordinatenreihenfolge vertauscht (lat/lon statt lon/lat)
  • Gleichheitsvergleich ohne Fließkomma-Toleranz

Prüffragen beim Code-Review:

  • Eingabe-KBS bestimmen
  • Einheit der Distanzberechnung prüfen
  • Polygonformat für die verwendete Bibliothek prüfen
# Fließkomma-Toleranz

from shapely.geometry import Point, LineString

p    = Point(1.0, 2.0)
linie = LineString([(0,0),(2,4)])

# Falsch: exakter Vergleich
if linie.distance(p) == 0:
    print("auf der Linie")

# Richtig: Toleranz
TOL = 1e-9
if linie.distance(p) < TOL:
    print("auf der Linie")
