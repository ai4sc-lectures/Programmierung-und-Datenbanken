Anweisungen

Anweisung

Eine Anweisung (engl. statement) stellt eine in der Syntax einer Programmiersprache formulierte einzelne Vorschrift dar, die im Programm nacheinander auszuführen ist.

Ausdrücke

Eine besondere Form von Anweisungen sind Ausdrücke (engl. expression), die immer einen Wert zurückgeben und damit einen Datentyp haben.

Operator

Ein Operator ist ein Teil von Ausdrücken und ein Symbol oder Schlüsselwort, das dem Compiler oder Interpreter mitteilt, eine bestimmte Operation auf Werte auszuführen.

Agentischer Arbeitsablauf: Logische Ausdrücke

Agentic Cycle

Wenn KI if not x is None and x > 0.0: generiert: vor dem Ausführen nachverfolgen.

  1. Vergleiche zuerst: x is None und x > 0.0
  2. Dann not auf das Ergebnis von x is None anwenden
  3. Zuletzt and verknüpft beide Teile
  4. Klarere Schreibweise prüfen: x is not None and x > 0.0

Überladen: Derselbe Operator, andere Bedeutung

Je nach Datentyp bedeutet derselbe Operator etwas anderes.

"Der " + "Ball"          # str
[1, 2, 3] + [2, 3, 4]    # list
{1, 2, 3} - {2, 3, 4}    # set
  • + verbindet Strings und Listen.
  • - bildet die Differenzmenge bei Mengen.
  • + ist für Mengen nicht definiert.

Welcher der beiden Ausdrücke ist True?

Übungsaufgabe: KI-Code nachverfolgen

KI hat diesen Code generiert:

ergebnis = not x is None and x > 0.0

Bestimmen Sie auf Papier den Wert von ergebnis für

  1. x = 10
  2. x = None
  3. x = "5"

Gehen Sie wie folgt vor:

  1. Operatoren und Rangfolge bestimmen
  2. Jeden Teilausdruck einzeln auswerten
  3. Ergebnis vorhersagen
  4. Erst dann ausführen

Lösung: KI-Code nachverfolgen

Für x = 10:

x is None      # False
not False      # True
x > 0.0        # True
True and True  # True

Für x = None: not x is None ergibt False. Wegen and wird x > 0.0 nicht mehr ausgewertet, das Ergebnis ist False.

Für x = "5": x is None ist False, not ergibt True, dann scheitert "5" > 0.0 mit einem TypeError.

Klarer schreiben

ergebnis = (x is not None) and (x > 0.0)

Klammern machen die Rangfolge explizit. Der Typ von x bleibt trotzdem zu prüfen.
